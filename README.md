# GRIZ HQ — Montana Football Fan Hub

This is the first static version of a fan-built Montana Grizzlies football information site.

## Run it locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository, e.g. `griz-hq`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Go to Settings → Pages.
5. Choose "Deploy from a branch", select `main`, folder `/root`, and save.
6. GitHub will provide a free `github.io` address.

GitHub Pages includes hosting at no separate hosting charge.

## Custom domain
Later, buy a domain such as `grizhq.com` or another available name from a domain registrar.
GitHub Pages supports custom apex and `www` domains.
